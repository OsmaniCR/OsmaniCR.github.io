# OsmaniCR.github.io

Portafolio personal de Osmani Casanueva Rodríguez, Ingeniero Industrial y Desarrollador de Software.

## Stack

- React
- TypeScript
- Vite
- CSS moderno
- GitHub Actions

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run build
```

## Despliegue

Este sitio está preparado para GitHub Pages desde la raíz del repositorio `OsmaniCR.github.io`.

## Estructura

- `src/data/portfolio.ts`: contenido editable del portafolio
- `src/sections/`: secciones principales
- `src/components/`: componentes reutilizables
- `public/`: favicon, sitemap, robots, 404 y metadatos visuales

## Actualización de contenido

Edita `src/data/portfolio.ts` para cambiar enlaces, textos, servicios, casos de estudio y stack.

## Privacidad

Los casos de estudio están redactados de forma anónima y de alto nivel. No incluyen secretos, datos personales ni información sensible de clientes.
